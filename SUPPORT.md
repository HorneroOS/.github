# Support

## Documentation

Start with the official documentation in
[HorneroOS/docs](https://github.com/HorneroOS/docs).

## Questions and discussion

- General questions about Hornero OS as a product:
  [HorneroOS/hornero discussions](https://github.com/HorneroOS/hornero/discussions).
- Component-specific questions: use the issue tracker of the relevant
  repository ([shell](https://github.com/HorneroOS/shell),
  [config](https://github.com/HorneroOS/config),
  [installer](https://github.com/HorneroOS/installer),
  [website](https://github.com/HorneroOS/website)).

## Bug reports

Open an issue in the repository that owns the broken component, with steps to
reproduce, expected vs. actual behavior, and environment details.

## Security issues

Do not use public channels. See [SECURITY.md](SECURITY.md).
