# `.github`

Organization-wide GitHub configuration for [HorneroOS](https://github.com/HorneroOS):
community health files, contribution standards and the organization profile.

Hornero OS is an Arch Linux-based desktop operating system built around
Wayland, Hyprland and Quickshell, with a distinctive Argentine-inspired
identity and a long-term focus on deeply integrated AI-native computing.

## Contents

- [`profile/README.md`](profile/README.md) — the public HorneroOS organization profile.
- [`CONTRIBUTING.md`](CONTRIBUTING.md) — contribution standards inherited by all HorneroOS repositories.
- [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) — expected behavior in HorneroOS spaces.
- [`SECURITY.md`](SECURITY.md) — how to report security issues.
- [`SUPPORT.md`](SUPPORT.md) — where to get help.

Files at the root of this repository are inherited as community health files by
every repository in the HorneroOS organization that does not define its own.

This repository contains no implementation code.
