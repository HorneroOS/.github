# Hornero OS

An Arch Linux-based desktop operating system built around Wayland, Hyprland and
Quickshell — with a distinctive Argentine-inspired identity and a long-term
focus on deeply integrated, AI-native computing.

![Hornero OS desktop](https://raw.githubusercontent.com/HorneroOS/shell/main/docs/assets/desktop-hero.png)

> The project is in its early stages. Most components are still being defined;
> the repositories below reflect the current state of each part.

## ✨ Highlights

- **Quickshell desktop shell** — bar, launchers, dashboard, notifications and
  session controls, all in QML on Wayland.
- **Cinematic greeter** — an SDDM greeter featuring offline Argentine landscapes.
- **Declarative config** — reusable desktop and system defaults, versioned as code.
- **Documented architecture** — user, developer and architecture docs live alongside
  the code.
