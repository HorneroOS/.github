# Hornero OS

Hornero OS is an Arch Linux-based desktop operating system built around
Wayland, Hyprland and Quickshell, with a distinctive Argentine-inspired
identity and a long-term focus on deeply integrated AI-native computing.

> The project is in its early stages. Most components are still being defined;
> the repositories below reflect the current state of each part.

## Repositories

- [hornero](https://github.com/HorneroOS/hornero) — distribution composition, release manifests and system integration.
- [shell](https://github.com/HorneroOS/shell) — the desktop shell, built with Quickshell, QML and Qt for Wayland.
- [config](https://github.com/HorneroOS/config) — reusable desktop and system defaults.
- [installer](https://github.com/HorneroOS/installer) — installation application and workflows.
- [docs](https://github.com/HorneroOS/docs) — user, developer and architecture documentation.
- [website](https://github.com/HorneroOS/website) — official product website.
